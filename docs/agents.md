## Design Guardrails

1. **Read-write hardware & hook separation**: `arch-redteam` and `staff-gatekeeper` physically omit all canonical (`write_file`, `edit_file`, `create_file`, `delete_file`) and legacy (`write_to_file`, `replace_file_content`, `multi_replace_file_content`) write tools while all 3 include canonical `read_file` alongside legacy aliases. Frontmatter `hooks:` backed by [`harness-subagent-guard.sh`](../scripts/harness-subagent-guard.sh) unconditionally locks `.artifacts/{SPEC,CONSTRAINTS,PLAN}.md` for `slice-builder` (plus `.agents/*` & `scripts/harness-*.sh` unless workspace root `plugin.json` has `name: "agy-harness"`), blocks `IsDaemon: true` / `WaitMsBeforeAsync > 10000` / container & install blacklists, and confines `staff-gatekeeper` `run_command` to short read-only checks.
2. **4-in-1 consolidation & CRG-coexistent discovery**: Turn 1 orientation uses fast parallel native reads (`read_file` / `grep_search` / `find_by_name`) by default and honors CRG only when a workspace explicitly enables `.agents/rules/crg.md`; `staff-gatekeeper` merges quality, simplification, anti-fake-test checks, and security/performance audits in a single pass.
3. **Per-slice closed-loop lifecycle**: Keep `slice-builder` and `staff-gatekeeper` alive via `send_message` across gate fixes, `NO-GO` rework, and `[HOST_CMD_REQUEST]` cycles within Slice `N`; once Slice `N` passes `GO`, `manage_subagents(Action="kill")` destroys Slice `N` subagents before spawning fresh clean-context subagents for Slice `N+1`.
4. **Circuit breaker (`Max Retries = 2`) & Static `Permissions` layering**: Only `[BLOCKER]` and `[CRITICAL]` findings trigger `NO-GO` rework (`[NIT]` items do not loop). Pair AGY native `Permissions` (`Deny > Ask > Allow` for static `.env`/credential or `git push --force` rules) with `agy-harness` Hooks for dynamic contract/lifecycle enforcement.
5. **Persona lint contract (`scripts/validate-skills.js`)**: Every `agents/<name>.md` must carry valid YAML frontmatter with `name` matching the file stem and a `description`, and end with `## Composition` as its final `##` heading.
